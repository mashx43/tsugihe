# Tsugihe

Tsugihe は、キーボードショートカットを使用してウェブサイトの「次へ」や「前へ」のページに素早く移動できるブラウザ拡張機能です。URLを解析して次・前のページを推測するほか、特定のサイト向けにカスタムルールを定義することも可能です。

## 主な機能

*   **キーボードショートカット:** マウスを使わずに、ページ分割されたコンテンツを移動できます。
*   **カスタマイズ可能なルール:** デフォルトでサポートされていないサイトでも、正規表現を使用してカスタムURLパターンを追加できます。
*   **サイト別設定:** 拡張機能を動作させたくないサイトでは、個別に無効化設定が可能です。
*   **キー設定:** 「次へ」「前へ」のナビゲーションに使用するキーを好みに合わせて変更できます。

## 使い方

1.  拡張機能をインストールします。
2.  ページネーションのあるサイト（ニュース記事、検索結果、漫画など）を開きます。
3.  デフォルトのショートカットキー（または設定したキー）を使用して、次のページや前のページに移動します。
